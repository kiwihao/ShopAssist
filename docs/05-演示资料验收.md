# 第 3 步：演示资料验收

日期：2026-11-01；数据集版本 demo-v1。

## 已准备

- data/demo/products.csv：两款商品属性、商品 ID、文档路径与版本。
- data/demo/documents/BP-A-v1.md：轻行通勤包商品说明。
- data/demo/documents/BP-B-v1.md：简装轻便包商品说明。
- data/demo/README.md：字段单位、输入职责、未知信息和本机查看命令。

属性 CSV 用于后续硬条件筛选；Markdown 用于后续语义检索与引用。文件均为自定义演示输入，不冒充真实商家数据。标准答案和评测问题后续单独管理。

## 已核对

使用 PowerShell Import-Csv 及逐文档字符串匹配检查：

- 两款商品且 product_id 唯一。
- 每款商品关联的 Markdown 文件存在。
- 文档内商品 ID、版本、价格与电脑仓高宽厚和 CSV 一致。
- 每份文档明确演示性质和未提供最大承重。

实际结果：以上检查通过。两款商品的清洁方式差异已人工核对：A 仅湿布擦拭，B 可移除底板后手洗；两者均禁止机洗。
