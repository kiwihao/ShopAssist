# 商品问答页面验收

日期：2026-11-02。交付位置：web/。后端接口及数据库结构本轮未改动。

## 页面与运行

采用浅色商品工作台：左侧商品目录，中间问答，右侧可展开的原文资料；窄屏将右侧资料收为抽屉。颜色以白色 #FFFFFF、浅灰绿 #F5F7F6、松绿 #176B52、墨绿 #223E34、浅叶绿 #EDF4E8 为主，字体使用本机系统字体。两款背包使用原创 SVG 演示插画，没有新增远程图片和字体请求。

先运行 Java 后端和数据库、Ollama。前端启动：

```powershell
Set-Location D:\study\codex\program_two\web
npm ci
npm run dev
```

访问 http://127.0.0.1:5173 。后端默认 http://127.0.0.1:8081 。构建执行 `npm run build`，预览执行 `npm run preview`，预览端口 4173。详细说明见 [前端 README](../web/README.md)。

页面只通过 /api/products 和 /api/qa 调用 Java。Vite 的开发与预览代理负责转发；浏览器不持有模型 Key，也不直连模型或数据库。

## 浏览器实际验证

使用 agent-browser 对本机实际 Java 服务联调，并检查桌面 1440×1000、手机 390×844 和 320×740 视口。

| 场景 | 验证方式与结果 |
| --- | --- |
| 加载商品 | 从真实接口展示 BP-A、BP-B、商品名称及演示价格 |
| 快捷提问 | 点击尺寸问题，真实返回 BP-A 的 36×25×3 cm 与原文引用 |
| BP-B 清洁说明 | 真实回答禁止机洗、取出底板后冷水手洗，引用 B 文档 |
| 资料不足 | 实际询问最大承重，显示“资料暂未说明”，未给出公斤数 |
| 条件不足 | 实际询问电脑能否放下，显示“需要补充信息”并要求尺寸等条件 |
| 查看引用 | 显示文档名、版本、标题、行号、原文及适用商品；能展开/收起 |
| 请求失败与重试 | 在测试浏览器中拦截问答请求制造网络失败，显示 NETWORK_ERROR 与重试入口；解除拦截后重试成功。未停止真实后端或上游 |
| 请求中切换商品 | 在测试浏览器中额外延迟问答请求，B 等待期间切到 A，A 仍显示 A 的记录与引用；切回 B 后，B 收到自己的 32×23×2 cm 回答 |
| 输入与长度 | Enter 发送；Shift+Enter 实际插入换行；1001 字时提示超长并禁用发送 |
| 清空记录 | 清空当前商品后回到快捷提问，其他商品记录保留 |
| 手机布局 | 商品横向选择、底部输入框、引用抽屉；320px 视口没有页面横向溢出 |
| 抽屉键盘操作 | 打开后焦点进入关闭按钮，Tab 在抽屉内循环；Escape 关闭后返回触发按钮，背景解除 inert |
| 构建版本 | TypeScript 检查与 Vite 构建通过；通过 4173 的打包预览页面成功发起真实问答；该页无未捕获脚本异常 |

## 实现边界

- 问答历史按商品保存在当前页面内存，刷新会清除；不向后端发送历史。它不是多轮记忆或用户隔离。
- 页面展示“后端已连接”表示商品接口可访问，不代表聊天或向量模型健康。
- 加载和等待状态来自真实请求，没有演示答案或假流式回复。客户端超时为 210 秒；重试由用户主动发起。
- 接口回答文本作为 React 文本渲染，不执行 HTML 或模型返回的脚本。
- 当前没有推荐、工单、上传管理页面；没有前端 Docker 镜像或正式部署验收。
- 这些页面检查验证交互与接口联通，不等同于 RAG 召回、回答准确率、幻觉率或成本评测。
